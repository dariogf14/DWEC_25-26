# Discoteca Virtual

Aplicación Express con patrón MVC para gestionar artistas y álbumes en memoria.

## Funcionalidades

- Página de inicio.
- Listado de álbumes.
- CRUD completo de álbumes.
- Listado de artistas.
- Ficha de detalle de artista con sus álbumes.
- CRUD completo de artistas.
- Validación de servidor en formularios.
- CSS propio.
- Fotos y placeholder.
- Logging HTTP con Morgan en `access.log` cuando se ejecuta en local.
- Preparada para desplegar en Vercel.

## Instalación local

```bash
npm install
npm start
```

Abrir:

```txt
http://localhost:3000
```

## Despliegue en Vercel

1. Subir este proyecto a un repositorio de GitHub.
2. Entrar en Vercel.
3. Crear un proyecto nuevo importando el repositorio.
4. Deploy.

La URL pública será similar a:

```txt
https://discoteca-virtual.vercel.app
```
